# Parcelo

Parcelo is a small command-line client for tracking parcels. Use it to look up a single parcel or list parcels by status.

!!! note "Pilot project"
    Parcelo is not a real service. The project exists to try out AI-assisted documentation updates, and all parcel data is made up.
