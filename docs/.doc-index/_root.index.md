# _ROOT Documentation Index

## Overview
This documentation area contains the landing page (`index.md`) for the Parcelo project documentation. It provides a high-level introduction to the Parcelo command-line client, notes the project's pilot status, and serves as the primary navigation hub linking to installation, quickstart, configuration, and CLI reference guides.

## Files Summary
* `index.md`: Serves as the main entry point and landing page for the Parcelo documentation, summarizing the project's utility and routing users to key guides and reference pages.

## Code Changes That Would Require Documentation Updates
* Changes to the overall purpose, core features, or high-level scope of the Parcelo application (e.g., adding capabilities beyond tracking parcels by ID or status).
* Shifts in project status, maturity, or scope (e.g., transitioning Parcelo from a pilot project with mock data to a production service with real data feeds).
* Renaming, moving, adding, or deleting major documentation pages referenced in the landing page links (e.g., structural changes to `getting-started/` or `reference/` sections).

## Key Technical Concepts
* **Parcelo CLI**: Command-line interface client for tracking parcels.
* **Parcel Tracking**: Core feature allowing lookup of individual parcels or listing parcels filtered by status.
* **Pilot Project**: Clarification that the application uses synthetic/mock parcel data for doc testing purposes.
* **Documentation Navigation**: Direct links to installation (`getting-started/install.md`), quickstart (`getting-started/quickstart.md`), configuration (`reference/configuration.md`), and CLI reference (`reference/cli.md`).

## Related Components
* **Parcelo CLI Core Application**: The underlying executable tool used for parcel lookups.
* **Documentation Suite**: The overall documentation structure including `getting-started/` and `reference/` folders.
