# Install Parcelo

Parcelo requires Python 3.10 or later.

## Install from source

```bash
git clone https://github.com/YOUR-USERNAME/parcelo-docs-pilot.git
cd parcelo-docs-pilot
pip install -e .
```

## Verify the installation

```bash
parcelo --help
```

The command prints the available subcommands. If the shell reports `command not found`, make sure the Python scripts directory is on your `PATH`.
