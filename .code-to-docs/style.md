# Documentation style

- Write in Markdown for MkDocs Material. Do not add front matter.
- Use active voice and present tense.
- Use sentence case for headings.
- Address the reader as "you".
- Keep paragraphs to three sentences or fewer.
- Put environment variables, flags, commands, and values in backticks.
- Keep existing tables as tables. Add a row instead of writing a new paragraph.
- Change only what the code change requires. Do not rewrite unrelated sections.
- Do not invent features, defaults, or examples that are not in the code diff.
